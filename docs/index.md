# pytest-race

<https://github.com/idlesign/pytest-race>

*Race conditions tester for pytest*

Introduces **start_race** fixture to run race condition tests.

## Requirements

1. Python 3.10+
2. pytest 2.9.0+

## Install

```shell
$ python -m pip install pytest-race
```

See [Usage](010_usage.md) for the details.
